# bank/ — 보고서 공유 스냅샷

이 폴더는 협력사 변경 검토 보고서의 **공용(팀 전체) 스냅샷**입니다.
여기에 커밋된 보고서는 `index.html`의 `EMBEDDED_REPORTS`에 함께 반영되어,
어느 기기·어느 브라우저에서 대시보드를 열어도 동일하게 조회됩니다.

## 왜 필요한가

대시보드는 완전 정적 파일이라 새로 작성/상태변경한 보고서는 기본적으로
그 브라우저의 localStorage에만 저장됩니다 (다른 사람·다른 PC에서는 안 보임).
`bank/`는 그 로컬 데이터를 주기적으로 모아 저장소에 커밋해두는 "공용 인덱스"입니다.

## 구성

- `reports.json` — 전체 보고서 스냅샷 (병합·정렬된 canonical 데이터, `index.html`의 EMBEDDED_REPORTS 생성 소스)
- `<id>-<굿즈명>.md` — 보고서별 마크다운 (저장소에서 바로 읽을 수 있는 사람용 사본)
- `sync_bank.py` — 동기화 스크립트

## 동기화 방법

1. 대시보드 상단 **[🗂 보고서 동기화]** 버튼 → **[📤 지금 내보내기]** 로 보고서 JSON을 받습니다.
   (내부적으로 기존 [📤 내보내기] 기능과 동일 — 로컬 스토리지의 모든 보고서를 내려받습니다.)
2. 받은 JSON 파일을 Claude Cowork 세션(이 저장소)에 업로드하고 "bank에 동기화해줘"라고 요청합니다.
3. Claude가 `python3 bank/sync_bank.py <파일>` 을 실행해
   - `reports.json`을 id 기준으로 병합하고
   - 보고서별 `.md`를 재생성하고
   - `index.html`의 `EMBEDDED_REPORTS` / `BANK_SYNCED_AT`을 갱신합니다.
4. 변경사항을 커밋·푸시하면, 다음에 대시보드를 여는 모든 사람에게 최신 스냅샷이 반영됩니다.

## 동기화 우선순위

같은 `id`의 보고서가 bank와 내 브라우저(localStorage) 양쪽에 있으면,
동기화 전까지는 **내 브라우저 쪽이 우선 표시**됩니다 (아직 반영 안 된 최신 변경사항을 잃지 않기 위함).
동기화가 끝나면 bank 스냅샷이 곧 최신 상태가 됩니다.
