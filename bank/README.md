# 📦 보고서 Bank

팀원들이 각자 컴퓨터에만 저장된(로컬 브라우저 localStorage) 협력사 변경 검토 보고서를 공유하기 위한 폴더입니다.

## 사용 방법

### 1. 내보내기 (내 컴퓨터 → bank)
1. 대시보드에서 **📤 내보내기** 버튼 클릭
2. 이름/이니셜을 입력하면 `SCM_보고서_백업_이름_YYYYMMDD.json` 형식으로 파일이 다운로드됩니다 (생략 가능)
3. 다운로드된 파일을 GitHub 저장소의 이 `bank/` 폴더에 업로드합니다
   - GitHub 웹에서: 이 폴더로 이동 → **Add file → Upload files** → 파일 드래그 → Commit
4. 기존에 올렸던 내 백업 파일이 있다면 그 파일을 덮어쓰기(같은 파일명으로 업로드)해도 되고, 새 파일로 추가해도 됩니다 (가져오기는 보고서 `id` 기준으로 중복을 제거합니다)

### 2. 가져오기 (bank → 내 컴퓨터)
1. 대시보드에서 **🏦 Bank에서 가져오기** 버튼 클릭
2. 이 폴더의 모든 `.json` 파일을 자동으로 읽어와 내 브라우저에 병합합니다 (이미 있는 보고서는 건너뜀)

## 주의사항

- 파일명은 자유롭게 지어도 됩니다. 병합은 파일명이 아니라 각 보고서의 고유 `id` 값 기준으로 이루어집니다.
- 이 폴더의 파일을 직접 수정하지 마세요 (대시보드의 내보내기 기능으로 생성된 파일만 업로드).
- 이 저장소는 public이므로, 백업 파일에 민감한 정보(단가·협력사 정보 등 이미 대시보드에 포함된 내용 외의 것)를 추가로 넣지 마세요.
